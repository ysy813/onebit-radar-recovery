## 共同研究对象

各目标回波先叠加，再按规则对 I、Q 分量取符号，得到 ±64 两电平输入。后续利用频谱及局部/谐波支持线索预测标量幅值增益。模型不恢复复数相位，也不承担雷达运动补偿或完整物理 SAR 聚焦。

| 项目 | compact 硬件版 | 最新 PC 后级版 |
|---|---|---|
| MLP | 40 → 32 → 16 → 1，1857 参数 | 相同层宽与参数量 |
| 直接输入来源 | 原单比特 FFT 功率 | CPU 前端恢复幅值产生的代理功率 |
| 权重来源 | 冻结 v2 权重 | 从旧 40 维模型继续训练 |
| 幅值增益范围 | 1/8–1.5 | 1/64–1.5 |
| 固定保护 | 原软弱峰保护＋512 chirp 紧凑保护 | 主候选不加固定保护；另有同权重保护消融 |
| 数值实现 | 特征 Q12、内部 Q16、增益 Q14 | PC 浮点；尚未适配该版 PL 定点规则 |

## compact 的数值路径

输入为自然距离顺序的 1024×512 `uint64` 功率矩阵。网络预测幅值增益，功率按增益平方写回：

```text
Pout = sat_u64((Pin × g_q14 × g_q14 + 2^27) >> 28)
```

`g_q14` 为 Q14 幅值增益，舍入和饱和规则属于接口的一部分。板端功率 DDR 的 Doppler 列含 256 点 shift，IP 显式转换列地址；不能只比较浮点模型的层结构就认定 PC/PL 等价。

完整位宽、存储布局与保护说明见[硬件工程文档](../hardware/radar1_scalar_compact_exp_v1/工程与网络说明.md)。紧凑保护不是目标检测器，不能保证所有真实目标保留。

## 最新 PC 后级怎样去伪

符号残差前端输出相对恢复幅值 `A`。使用原单比特功率峰 `Ppeak` 构造代理功率，再提取旧基础特征并派生 40 维：

```text
Pproxy = round(A² × Ppeak)
s      = MLP(features(Pproxy))
g      = 2^clip(s, −6, log2(1.5))
Aout   = A × g
```

`Pproxy` 是网络输入代理，不是校准后的绝对物理功率。输出不再次单独拉伸。纯幅值乘法不能从已经为零的恢复输入中重新生成目标。

本轮同时改变了增益下限、训练输入和保护设置；与旧模型的总改善不能全部归因于某一个损失项。

## 训练、选模、最终评价分开记录

| 阶段 | 规则 |
|---|---|
| 初始化 | 两组使用同一旧 40 维权重，不是随机从零训练；继承权重有历史实测数据影响 |
| 训练对照 | 输入适配组 / 加强去伪组，同批次、同预算，各 8000 步 |
| 共同损失 | 幅值误差、限幅前分数监督、主要目标与弱目标中心误差 |
| 去伪组增项 | 加强伪影分数监督与正超额幅值损失 |
| 抽样比例 | 25% 目标区域、50% 伪影区域、25% 混合池 |
| 验证选模 | 2000/4000/6000/8000 步中选择；先少主要目标半幅失败，再比较残峰、最强伪峰、超额能量、目标误差 |
| 最终选择 | 两组均选第 4000 步；测试不参与选模 |

具体系数、数据种子和预声明判据见 [PROTOCOL.json](../pc/scalar_postrestore_suppress_v1/PROTOCOL.json)，选模证据见 [FROZEN.json](../pc/scalar_postrestore_suppress_v1/FROZEN.json)。这些是本轮研究设计，不是行业标准。

## 68 帧如何划分

| 划分 | 帧数 | 来源与用途 |
|---|---:|---|
| 训练 | 44 | 此前符号研究 20 帧＋融合扫描 12 帧＋新增 12 帧；前 32 帧已看过，转为训练 |
| 验证 | 12 | 新种子，仅用于选模 |
| 最终测试 | 12 | 冻结后生成的新种子，当时用于最终评价；现在已读取 |

训练池有 **165931 行抽样点**，保留 `frame` 和 `pixel` 映射；重复抽样点不能算作新的独立帧。场景来自同一个点频仿真生成族，未加入噪声、杂波或完整车载/近场传播模型，不能据此声称真实环境泛化通过。

## 文件里存的是什么

| 数据 | 主要内容 | 是否供模型推理直接使用 |
|---|---|---|
| 输入 NPZ | 原 ADC I/Q、符号观测、多比特及单比特 FFT 功率 | 依前端或特征接口而定 |
| 恢复谱 NPZ | 同帧各支路的相对幅值 | 后级使用恢复幅值字段 |
| 训练池 NPZ | 基础特征、监督值、标签、帧编号、频点索引 | 仅训练/复查 |
| 最终输出 NPZ | 原分辨率方法输出 | 数值评价与复查 |
| PNG / HTML | 中文可视化 | 不作为训练输入 |
| 原始板测 BIN | 量化前 RX0 原始 I/Q | 属于硬件短测证据，不属于上述仿真 68 帧 |

[DATA_CATALOG.json](../manifests/DATA_CATALOG.json) 同时保留原来源路径、种子、SHA256，以及 `*_repository_path` 相对路径。换机器查找数据时使用相对路径；历史 JSON 中的绝对路径保留用于溯源。

研究数据包覆盖当前 68 帧、相关恢复结果、训练池与本轮输出，不是所有历史实验及实测数据的全量备份。每个附件的内容清单见 [RELEASE_ASSETS.json](../manifests/RELEASE_ASSETS.json)。
