# 术语与自测：用自己的话说清楚

这份自测供自主阅读，不是要求你现在逐题答复。后续讨论可以直接说题号。

## 高频术语

| 词 | 在当前工程中的意思 |
|---|---|
| 单比特 | I和Q分别保留符号，两种电平；不是已经换成单比特ADC |
| RD | 快时间/慢时间二维FFT形成的频谱域表示；物理坐标仍需参数和几何 |
| 谐波 | 非线性产生的原频率整数倍分量，复I/Q符号量化有正负方向 |
| 互调 | 多个输入分量经非线性后产生的组合频率，不只是单目标倍频 |
| 折叠/别名 | 离散频谱以采样频率为周期，超出后按索引取模 |
| 特征 | 从输入中提取、送给网络的数值提示，不是目标真值 |
| MLP | 若干全连接层和非线性；当前逐点共享同一套权重 |
| 参数 | 训练后固定的权重和偏置，当前1857个 |
| 激活 | 给定输入后各层算出的中间数，每帧/每点变化 |
| MAC | 一次乘法并累加；参数小仍可能重复计算很多次 |
| 增益 | 当前输出的幅值倍数，不是分类概率 |
| 保护 | 使用输入规则减轻某些额外误压，可能保留伪影 |
| Q16 | 16位小数缩放约定，不表示总字长一定16位 |
| 归一化 | 按帧峰值转换相对尺度，不保留绝对回波强度 |
| 旁路 | 同一单比特FFT不使用网络修正；不是多比特参考 |
| 消融 | 固定其它条件，去掉某个模块，量化它对结果的贡献 |
| 留出 | 模型选择时不使用的数据；读取并参与后续设计后不再是新盲测 |
| 工程验证 | 检查实现、接口和运行；不自动等于恢复质量验证 |

## 第一组：理解信号

**1. x和10x会不会得到相同的I/Q符号？这说明什么？**  
答案：会，正尺度不变；绝对幅度不能唯一逆推出。

**2. 理想复正弦在(100,20)，第三谐波在哪？**  
答案：(−300 mod1024,−60 mod512)=(724,452)。两个维度都变化。

**3. 谐波幅值为基波1/3，功率是多少？**  
答案：1/9；幅值与功率不能混用。

**4. 有个点符合三次关系，能直接判伪目标吗？**  
答案：不能，真实目标可能重合，还有泄漏和互调；它只是提示。

## 第二组：理解结构

**5. 一个点的网络输出g=0.5，功率100，写回多少？**  
答案：理想计算25，而不是50。

**6. 功率是0，g最大1.5，能生成缺失目标吗？**  
答案：不能，0乘g²仍是0。

**7. 40维里是否包含固定目标坐标？**  
答案：没有目标真值坐标；但谐波查找使用FFT索引关系，邻域按周期处理。

**8. 权重是不是每帧重新算？1857是不是每个位置不同的1857个参数？**  
答案：训练后固定，所有位置共享；每点激活和增益会改变。

**9. 为什么增益为0.4的弱峰可能回到1？**  
答案：符合保护资格时，第一层w=(0.4−0.25)/0.25=0.6，g1=0.76；若第二层紧凑度c=1，则因w(g1)=1，g2=1。这只是教学假设，不是某个真实目标的实测值。

**10. 背景压得很黑，是否就恢复得很好？**  
答案：不一定，也可能把弱目标压没；需要同尺度参考、目标与背景指标共同评价。

## 第三组：理解训练和实现

**11. 推理时是否必须同时传多比特参考给FPGA？**  
答案：不需要，参考用于训练和离线评价。

**12. 62条缓存是不是62个独立场景？**  
答案：不是，包含同源通道、排列与合成记录。

**13. Q16是不是16位累加器？**  
答案：不是，小数缩放与总位宽分开；当前累加器48位。

**14. 500ms输入60帧，网络只完成6帧，存储可以保存60帧吗？**  
答案：可以，原始存储在上游独立分流；当前测试就是这样。成像忙帧跳过，不是网络全部排队。

**15. 什么情况下能说“当前方法优于旧V7”？**  
答案：必须限定数据集、指标与条件。当前有些NMSE指标更好，但512合成背景正误差仍高于V7，不能无条件全面宣称。

## 第四组：理解训练与保护的边界

**16. 参考y=0.08、单比特x=0.02，当前网络能精确恢复吗？**  
答案：不能。最大幅值增益1.5，只能到0.03；幅值参考没有被裁成0.03，训练中仍会有残差。

**17. 损失含“0.52参考半幅保护”，是否保证所有目标都不低于0.52参考？**  
答案：不保证。这是有限权重软惩罚，还有参考掩码和原x≥0.5y的条件，不是全体谱点的硬约束。

**18. 保护规则是否和MLP一起端到端训练？**  
答案：当前版本没有。最终compact沿用冻结v2权重，再由输入驱动规则调整增益。

**19. 512分支的紧凑峰若原g=0.125，会自动救回到1吗？**  
答案：不会。当前两层连续提升在增益≤0.25时都不抬升；紧凑度高不是唯一条件。

**20. compact对128分支不新增修改，是否表示128没有保护？**  
答案：不是。它保留原v2输出，第一层仍有该分支的弱峰和峰值保护；不能只凭补零后尺寸相同混用512规则。

## 第五组：把公式和板端对应

**21. Q12整数3006左移4位变成Q16，数值精度提高了吗？**  
答案：解码数值仍为0.73388671875，只改变表示尺度；不会新增输入信息。更高内部精度用于减少后续计算的额外误差。

**22. 为什么偏置用Q32，激活却用Q16？**  
答案：两个Q16数相乘得到Q32乘积，偏置必须对齐；求和后舍入右移16位再变回Q16。

**23. 看到image_preprocess接xfft，是否说明网络放错位置？**  
答案：这条线负责FFT前I/Q量化。真正scalar_gain另走AXI访问FFT后功率缓存，不能把控制器/预处理与数值IP混为一谈。

**24. 日志计时在250MHz域，是否说明MLP也运行于250MHz？**  
答案：不是。当前核心100MHz，控制器250MHz，两域用握手连接；日志计数除250000得整数毫秒。

**25. 一帧每个点的增益能否算一个就立即改一个功率？**  
答案：当前实现不能随意这样改。后续点还要读原功率邻域和弱峰条件，提前写回会污染同帧输入；当前先算全帧增益，再统一写回。
