# 当前网络与CDQOB-Net：恢复方向相近，变量与算子不同

## 1. 原网到底想解决什么

原论文研究单比特SAR处理中的谐波与互调污染，把二维FFT后的RD域恢复作为子问题：从量化后退化的图像估计更接近多比特参考的图像，再结合运动与几何完成后续成像处理。不是对任意2DFFT数据都通用的无条件增强器。

论文的主要路线是：分析非线性产生的谐波折叠，在图像域估计退化关系，再用CNN学习输入自适应的修正。论文第7–8页说明H估计模块及清洁图像生成模块，并给出先MSE、后MSE加ResNet50感知损失的训练描述。

应区分“论文描述”和“手上交付代码/权重实际证明了什么”。交付代码中实际运行的是六层卷积加拼接，再用逐点表达式生成RGB输出；没有证据可把所有训练细节都仅凭论文照搬到交付权重上。

## 2. 原交付网络的具体结构

输入是3通道RGB，代码中的六层卷积如下；空间步长1，SAME填充，每层带ReLU。

| 层 | 核尺寸 | 输入通道 | 输出通道 | 权重MAC/空间点 | 偏置数 |
|---|---:|---:|---:|---:|---:|
| c1 | 1×1 | 3 | 3 | 9 | 3 |
| c2 | 3×3 | 3 | 32 | 864 | 32 |
| c3 | 5×5 | 35，拼接c1/c2 | 32 | 28000 | 32 |
| c4 | 7×7 | 64，拼接c2/c3 | 32 | 100352 | 32 |
| c5 | 9×9 | 96，拼接c2/c3/c4 | 32 | 248832 | 32 |
| h | 1×1 | 128，拼接c2/c3/c4/c5 | 3 | 384 | 3 |
| 合计 |  |  |  | 378441 | 134 |

参数总数378441+134=378575。对应最长局部感受野为21×21。卷积核3×3、5×5表示局部邻域尺寸，不能因为数字相同就说它们分别等于三次、五次谐波物理关系。

实际交付输出头为：

$$I_{\rm out}=\operatorname{clip}(h(I)\odot I-h(I)+1,0,1),$$

按RGB通道逐点计算。这里h是CNN估计的图像修正参数，不等于我们功率域的幅值增益g。论文第7页式(28)的印刷表达与代码中的+1存在差异，引用原理可以引用论文，描述交付实现必须以代码为准。

### 2.1 原网的h具体控制什么

先只看一个归一化RGB通道值I∈[0,1]。最后卷积经过ReLU，因此h≥0。输出可以改写为：

$$I_{out}=\operatorname{clip}(1-h(1-I),0,1)=\operatorname{clip}(I+(1-h)(1-I),0,1).$$

这样更容易解释h的含义：

| 条件 | 对该颜色通道的作用 |
|---|---|
| h=1 | 保持I |
| 0≤h<1 | 输出不低于I，向1提升 |
| h>1 | 输出不高于I，可能截到0 |
| I=1 | 无论h为何，输出固定为1 |

这是固定I后输出头的性质。完整CNN中h本身也随整片邻域输入变化，因此不能将它误写成完整网络对输入I的单调性证明。RGB某一通道变大或变小也不直接等于雷达幅值增强或削弱，颜色编码可能是非单调的。

对I>0，当然可以在代数上事后定义一个比值g_eff=I_out/I。但它不等于当前受限幅值增益：

| 构造I | 构造h | RGB通道输出 | 事后通道比值 |
|---:|---:|---:|---:|
| 0.2 | 0.5 | 0.6 | 3 |
| 0.2 | 1.25 | 0 | 0 |
| 0 | 0.5 | 0.5 | 不存在有限乘法比值 |

这些只是用指定h解释公式，不是作者网络在新数据上的预测。当前幅值增益只允许0.125～1.5，严格零幅值仍输出零；因此即使暂时忽略RGB与雷达幅值的单位差异，两个输出头的算子族也不等价。把原h直接当作当前g会同时弄错作用公式、数值范围和变量含义。

## 3. 我们具体借鉴了什么，改变了什么

| 维度 | 原交付RGB网络 | 当前标量网络 |
|---|---|---|
| 任务 | 单比特退化RD图像恢复 | 单比特FFT相对幅值结构恢复 |
| 输入 | 经过可视化编码的RGB | FFT功率与输入派生的40维特征 |
| 结构 | 多尺度CNN、通道拼接 | 手工机理特征、共享40→32→16→1 MLP |
| 谐波信息 | 由图像局部多尺度特征学习关联 | 显式查询−3/+5倍频折叠及候选父提示 |
| 输出 | 三通道RGB图像 | 一个有界幅值增益g，功率乘g² |
| 监督 | 论文描述图像MSE/感知约束 | 配对数值幅值、增益及弱峰/背景复合损失 |
| 弱峰处理 | 不能从交付模型推出与本模型相同的规则 | 两层输入驱动软保护 |
| FPGA接口 | 任意RGB输出无法直接当作功率 | uint64功率原位修正，便于保留原插值 |
| 能力边界 | 图像域恢复，不能默认绝对幅相还原 | 不恢复复数相位、不搬移索引网格、不标定绝对功率；不保证峰值排序不变 |

相似点是利用量化失真的结构性，在变换域学习输入自适应修正，并以多比特参考为恢复方向。

当前模型不是原网中“只负责标量的某几层”直接切出来，不是原网等价重参数化，也没有完成保持原网全部效果的知识蒸馏。它是任务相近、受到原网机理启发的独立轻量设计。

### 3.1 真正共同的结构思想是什么

两者都可以理解为“先预测输入相关的修正系数，再用固定算子形成输出”：

$$\text{原RGB头：}\quad\Delta I=(1-h(I))(1-I),$$
$$\text{当前幅值头：}\quad\Delta A=(g(P)-1)A.$$

第一式在截位之前成立；最终RGB仍要clip。第二式忽略输出舍入，g包含当前保护规则。在两者中系数1都表示不修改，但修正分别围绕颜色分量的补值1−I和输入幅值A定义，含义不同。

原网用多尺度卷积和通道拼接从图像学习表示；当前将谐波地址关系与部分局部统计提前固定，再由小MLP学习组合。当前5×5只描述24个邻居，父子查询还可跨越整个频谱；不能把“原网最长21×21局部感受野”与“当前只有5×5输入信息”作为公平对比。

当前逐点MLP与二维上下文的关系、编码位置上界和原CNN最长21×21范围的源码核对，见[第二讲10.1–10.3节](C:/Users/yang/Desktop/SAR_IMAGE/network_understanding_v1/10_第二讲_40维特征与学习增益.md)。全帧归一化带来的公共尺度依赖，也不能等同于可学习的全局注意力或目标识别。

这种联系可以作为方法动机，但不推出参数、训练目标或恢复效果等价。应分别说明：借鉴量化恢复任务与输入自适应修正思想；重新定义标量目标、特征、增益回归、损失和弱峰保护。现有62条后期数值训练的监督来自同源多比特参考，见[训练参考来源](C:/Users/yang/Desktop/SAR_IMAGE/network_understanding_v1/21_网络主讲_训练参考与证据范围.md)；不把未审计的更早全部预训练历史扩写成已证明结论。

## 4. 为什么RGB输出不自动等于标量幅值

RGB通常经历归一化、幂次压缩和伪彩色映射。网络还可能把输出推离原色图对应的一维颜色曲线，因此“取一个颜色通道”“转灰度”“反查jet颜色”不保证得到唯一可信的物理幅值。

当前方案改在标量功率域定义任务，避免把可视化颜色误当作测量量。这是接口意义明确的优点，不意味着已经证明当前精度和原网相同。

论文汇报中建议说“将恢复目标改写为受约束的标量增益估计”，不要说“无损删掉RGB输出层”。

### 4.1 什么情况下颜色可以反算成标量

不能笼统说“RGB在数学上永远不可逆”。如果已知映射C:a→(R,G,B)，它在所考虑区间内是单射，归一化也已知，且没有未解决的取整、截断、缩放或渲染歧义，那么对位于其颜色曲线上的输出，可以反算对应相对标量。

需要特别区分两个问题：输入颜色映射能否反算，以及网络输出是否仍位于这条曲线上。原输出头没有强制第二个条件。

用一个刻意简单的已知灰度编码C(a)=(a,a,a)说明：输入a=0.4对应(0.4,0.4,0.4)。若指定h=(1,0.5,1.5)，原头的输出为(0.4,0.7,0.1)。没有任何单一a满足C(a)等于这三个不同分量。

这不是作者实际色图或其实际预测，只是证明该RGB输出头本身不保证标量曲线约束。给输出选择一个最近颜色或转灰度，属于额外估计步骤，不是精确逆变换；需要额外定义与验证。

即使使用上述连续可逆灰度编码，8位取整也可能丢失区别：a=0.2与0.2001都四舍五入到灰度51。这个小例子只演示取整，不冒充作者的预处理流程。我们目前没有完整确认作者RGB数据的标量生成与标定链，因此不能将示意映射当作其真实流程。

当前方法直接定义标量恢复目标，输出的数值意义明确；其准确性仍需当前实验支持。输出意义明确不等于已找回绝对功率、复相位或所有真实目标。

本轮只从原交付代码与兼容副本提取输出表达式，指定系数做6006组代数核对，原式、补值式和残差式一致；未加载权重推理。报告：[ORIGINAL_SCALAR_COMPARISON.json](C:/Users/yang/Desktop/SAR_IMAGE/network_understanding_v1/reports/ORIGINAL_SCALAR_COMPARISON.json)。核对PASS不代表质量比较或等价性通过。

## 5. 运算量怎样公平比较

卷积每个输出空间位置的权重MAC为：

$$\sum_l K_{h,l}K_{w,l}C_{{in},l}C_{{out},l}=378441.$$

当前MLP对应1808 MAC/位置，同为1024×512时：

| 项目 | 原RGB网 | 当前MLP |
|---|---:|---:|
| 参数 | 378575 | 1857 |
| 核心MAC/位置 | 378441 | 1808 |
| 核心MAC/帧 | 198412075008 | 947912704 |

核心MAC比约209.3倍，但原RGB网与当前网输入/输出语义不同；当前还需要特征、保护和DDR开销。不能写成“整机延时必然减少209倍”或“质量完全相同但计算减少209倍”。也不要把每点MAC数与模型参数个数混为一谈。

## 6. 理论依据分成哪几层

### A. 可以直接推导的部分

1. 符号量化的正尺度不变性：解释绝对幅度不可唯一恢复。
2. 理想复正弦的方波傅里叶展开：解释有符号奇次谐波。
3. 离散频谱取模：解释两维别名坐标。
4. 幅值与功率平方关系：解释g²接口。
5. 有界逐点增益：不重采样或搬移索引，零功率仍为零，并限制修改范围；逐点改值仍可能改变局部最大点与峰值排序，小正功率也可能因整数舍入归零。

这些是设计的数学支撑，不需要依靠“网络学出来了所以合理”。

### B. 文献支持的研究方向

原论文已分析RD域谐波折叠和学习式恢复，支持在这一域利用结构先验。但原论文实验的成功不能直接当作当前40维特征、MLP宽度和保护阈值的质量证明。

Bussgang理论在联合高斯等适用条件下，可以把非线性输出分解成与输入成比例的一项加上与输入不相关的失真。它有助于理解非线性仍可保留有用相关性；不能因此把失真说成独立白高斯噪声，也不能证明当前网络最优。

### C. 需要由当前实验判断的部分

40维选择、32/16隐藏宽度、1/5次编码、31×1门控、弱峰阈值与复合损失权重都含经验设计。它们有直觉与可追溯实现，但不是每个常数都有唯一理论解。

所以可靠表述是“机理启发的特征与受约束学习恢复”，不是“已经证明了当前网络完整最优性”，也不宜把它直接命名为求解物理方程的PINN。

## 7. 统计理论作为补充，不能喧宾夺主

在零均值联合高斯实变量假设下，符号相关满足经典arcsine关系：

$$E[\operatorname{sgn}x\,\operatorname{sgn}y]=(2/\pi)\arcsin\rho.$$

它说明某些归一化统计相关仍存在，但不保证一个有限帧里的每个目标可恢复。经典文献全文本次未逐页复核，此式在材料中只作背景，不是当前性能结论的依据。

Bussgang分解写作：

$$q=Bx+\eta,\quad E[\eta x^*]=0.$$

“不相关”不等于“独立”，更不等于失真在空间中是白噪声。对非高斯确定性强散射回波，不能直接套用联合高斯定理而不说明条件。当前主论证用第A层的信号推导，不依赖这一附加假设。

监督学习可以解释为在选定数据分布和损失下最小化经验风险。只有纯平方损失、充分模型能力等条件下，才讨论条件均值等最优估计；当前是复合损失，不能直接宣称达到了MMSE或Bayes最优。

通用逼近定理也不能证明40→32→16→1网络必然恢复正确，不在本模型有效性的证据链中使用。
