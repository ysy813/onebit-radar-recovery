# 当前网络：从理解到论文汇报

本资料固定研究当前已经实验部署的 compact 弱峰保护标量网络。自2026-11-04起停止模型迭代；当前主线是把原理、实现和证据讲清楚，直到你明确停止或调整。

先记住这句话：

> 我们在数字域对雷达复数I/Q做符号量化，经过二维FFT得到功率谱；再用谐波关联与局部结构特征驱动一个小型共享MLP，为每个谱点估计有界幅值增益，并用输入驱动的弱峰保护减轻误压制；修正后的功率谱继续进入原有AQ/AR插值和显示链路。

“共享”表示整帧所有位置共用1857个参数，不是每个位置都存1857个不同参数。“恢复”表示向配对多比特参考的归一化相对幅值结构靠近，不表示精确找回已丢失的全部信息。

## 第一轮应当形成的整体认识

~~~mermaid
flowchart LR
 A[原始多比特I/Q] --> B[PL分流]
 B --> C[原始SD存储]
 B --> D[数字符号量化 ±64]
 D --> E[原二维FFT]
 E --> F[uint64功率缓存]
 F --> G[特征提取 + 共享MLP + 弱峰保护]
 G --> H[功率乘增益平方]
 H --> I[原AQ/AR插值]
 I --> J[HDMI灰度预览]
~~~

图中的两次“原”很关键：网络没有重写FFT和插值几何，也没有承担RGB图像生成。它在功率域工作，主要任务是减轻单比特量化带来的结构性幅值失真。

## 怎样判断自己已经理解

暂时不看资料，能解释以下内容，才算掌握了基本链条：

1. 为什么理想复正弦的第三次谐波落在负三倍频率，而不是正三倍？
