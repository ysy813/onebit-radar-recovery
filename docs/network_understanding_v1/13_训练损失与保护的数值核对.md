## 4. 平均误差下降不保证弱目标保留

10000个背景点各有0.001误差，一个幅值0.1的目标原本准确，MSE=9.99900009999e-07。
把背景误差降为0，但把目标压到0.02，MSE反而降到6.39936006399e-07，即原来的0.64倍。
目标幅值却损失了80%。这是构造反例，说明为什么要分开报告总体误差与逐目标指标，不是本次新增质量失败。
