# 48维多峰证据网络实验

本目录是2026-11-11用户授权的独立PC训练与验证，不替换此前网络或上板工程。

建议按这个顺序查看：

1. `本轮训练结果.md`：结论、同数据四组对照、逐目标及逐阶失败。
2. `results/index.html`：全部48帧最终测试的中文对照；包括重合、近邻、强弱和复杂多目标。
3. `特征与训练设计.md`：新增8维、坐标细化、损失修正和原理边界。
4. `数据来源与复现.md`、`DATA_REGISTER.json`：数据地址、生成方式、种子、用途及源帧映射。

预定主候选为`candidate/f48_repair/model_float.pt`，48→32→16→1，共2113参数；同损失40维对照为`candidate/f40_repair/model_float.pt`。另两组沿用原联合损失，用于区分扩维与损失改动的效果。主候选不等于优胜模型，必须以最终报告判断。

输入为1024×512自然顺序的单比特2DFFT功率。推理仅提取输入特征，MLP预测限幅分数，再经原保护和增益平方修正功率。多比特参考仅在训练损失与评价中使用。量化仍是所有目标回波先相加，再统一对I/Q进行±64二电平量化。

`reports/STANDARD_CHECK.json`仅表示交付完整性；`reports/TEST.json`记录恢复质量和新增8维收益；`reports/INTEGER_SMOKE.json`仅是四帧Q16数值检查。三者不相互替代。`BUILD_STATUS.json`不授予硬件下载资格。本轮未构建IP/BIT/ELF，未访问板卡。

特别注意：新增坐标细化在整数多目标训练场景存在覆盖退步，详见结果报告。实现审计PASS不能解读为父子关系已被物理确认。最终测试已读取，后续据此调参需另建实验并使用新测试种子。
