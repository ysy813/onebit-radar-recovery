# 512 背景抑制复核

本次复核支持用户对图像的观察：当前新版在旧 512 chirp 实测开发数据上，背景和整体恢复均优于冻结 V7。不能把另一组 512 chirp 合成测试的背景指标退化，概括成全部 512 数据效果不好。当前效果应保留，后续优化优先处理已知目标误压及少数残留伪峰。

本次只做诊断，没有训练或发布 v3 网络，没有修改 v2、原工程、BIT/ELF，也没有访问板卡。原 v2 的质量 FAIL 记录不变；它表示预设检查未全部通过，不代表没有改善。

## 原有结果分别说明什么

| 数据 | 新版相较冻结 V7 | 解释 |
|---|---|---|
| 旧 512 chirp 实测，6 帧开发数据 | 平均整体误差约降低 26.2%，背景正误差约降低 38.0% | 用户看到的改善有数值支持；这些数据参与过开发，不是盲测 |
| 512 chirp 合成留出，8 例 | 平均整体误差约降低 21.8%，背景正误差约增加 19.1% | 总体更接近参考，同时部分背景残留较 V7 多；两者可以同时发生 |

整体误差为相对多比特参考的归一化幅值 NMSE；表中百分比来自原报告的逐帧指标均值。多比特与单比特分别按自己的帧峰归一化；网络输出沿用单比特标尺，不能解读为绝对功率标定。

背景区域定义为参考归一化幅值 <0.003，并排除已知合成目标周围 7×7 邻域；背景指标是输出超过参考的正向幅值误差平方和。1.10 倍 V7 的限制是此前预设的质量筛选线，不是硬件生成 BIT 的物理限制。

## 本次进一步核对

结果见 `background_audit.json`，脚本为 `audit_background.py`。8 例合成 512 数据合并统计：

| 指标 | 单比特旁路 | 冻结 V7 | 当前 v2 |
|---|---:|---:|---:|
| 背景正误差平方和 | 1.689520 | 0.566658 | 0.675158 |
| 背景正误差 RMS | 0.00063517 | 0.00036785 | 0.00040153 |
| 上项相对于单比特帧峰的 dB | −63.94 | −68.69 | −67.93 |
| 背景区域内幅值 ≥0.003 的局部极大数 | 4917 | 2283 | 1380 |
| 背景区域内幅值 ≥0.01 的局部极大数 | 765 | 557 | 719 |
| 背景区域内幅值 ≥0.03 的局部极大数 | 87 | 81 | 110 |

因此，19.1% 的平方误差增幅，对应这组背景 RMS 约增加 9.2%、约 0.76 dB；不能说整个画面明显变差。低阈值处的局部极大数反而减少，但较高阈值处有所增加，说明也不能把差异全部视为不可见底噪。这里仅为固定幅值阈值的局部极大计数，不是经 CFAR、目标匹配和物理标注得到的误警率；统计包含全部自然距离索引，没有为获得好指标去掉失败区域。

合并后的整体 NMSE 为旁路 0.214606、V7 0.102911、v2 0.084010；该合并指标按参考能量加权，与上表逐帧均值的百分比不同，不混用。

## 继续优化的实际理由和优先级

更明确的问题是合成例 `confirm_synth_116013_512`：同一个已知弱目标，旁路保留参考幅值约 59.1%，网络后约 46.1%，额外衰减约 2.2 dB。它仍在，不是完全消失；但不能因为背景更干净而忽略目标被额外削弱。这次留出共 120 个已知目标，该新增半幅损失为 1 个；旧报告的 3 个“新增参考峰损失”是另一种自动峰指标，不与已知目标数混为一谈。

下一轮保留当前背景改善，以目标保持、总恢复误差、残留伪峰共同判断。不要为了超过 V7 的背景指标而把真实散射一并压低，也不要只调阈值追逐旧门槛。以前看过的留出用于诊断，不能再次称新盲测。新模型是否进入 IP 实现应结合恢复质量、数值一致性、接口和资源时序分别说明；本次诊断没有授予现成上板资格。
