# 恢复后轻量网络去伪实验

本轮固定前面的v2残差候选恢复，重新训练后级40维网络，检验是否能剔除恢复谱留下的强谐波、互调和伪峰。主要目标为去伪，弱目标损失作为明确代价报告。旧工程与权重不覆盖。

完成后入口：[本轮结果](本轮结果.md)、[中文对照图](results/index.html)、[数据来源](数据索引.md)。只有reports/TEST_SUMMARY.json记录最终质量；reports/STANDARD_CHECK.json检查实现和来源，不代替质量。

## 改动、原理与对照

原第三路直接把恢复谱送进未适配的旧网络。本轮将同帧恢复幅值平方并乘原单比特功率峰得到uint64代理功率，从中提取旧32个基础特征、派生为40维，仍使用40→32→16→1的1857参数MLP。输出是标量幅值增益，不是RGB。

为允许更强去伪，本轮两组共同将增益下限从1/8降到1/64，上限仍1.5；训练时取消旧固定保护。下限改变是本轮共同设计，不能把与旧模型的全部差异只归因于重训。纯幅值乘法仍不能从零输入恢复目标。

- **适配对照**：从旧40维权重继续训练，针对恢复后的输入学习参考幅值/增益分数。
- **去伪主候选**：同初始化、同批次、同训练预算，额外增强伪影位置的增益分数损失和正超额幅值损失。
- **保护消融**：将主候选同一权重分别不加/加旧固定保护，观察保护是否重新抬高伪峰。主接口预定为无保护，不按测试结果换接口。

监督目标来自同一回波的多比特FFT参考；目标外不自动都当作谐波。伪影标签要求排除真目标9×9邻域、输出超过参考2倍且超额>0.0001。训练从强参考外峰及谐波区域重点采样。对主要目标保留幅值约束，避免清零假改善。所谓主要目标是参考峰相对幅值≥0.25的实验分类，不是近距必强或真实检测门限。

原始分数也直接接受监督，避免增益硬限幅外只有幅值损失时的零梯度问题。损失具体系数见PROTOCOL.json；不是行业通用最优参数。存在重叠目标或参考泄漏时，标签仍可能不足以描述实际场景。

## 数据与划分

训练44帧：v2全部20帧＋上一轮权重扫描12帧＋新12帧。历史数据已被看过，明确转作训练，不再称留出或盲测。验证12新帧只选checkpoint；冻结后再生成最终12新帧。新场景按设计覆盖1–5、5–20、20–39.5m父目标范围；重合目标按倍频折叠可能超出40m，因此主区域与全频谱指标同时保留。

没有新增实测训练；继承的旧网络权重仍有历史实测影响。回波先叠加、统一缩放为整数ADC，再I/Q各自零阈值量化±64。零值归正电平，保持当前规则。近距数据只是点频RD模型，不包含真实近场电磁效应。

训练池保存基础特征、参考/恢复幅值、标签、源帧编号和原始频点索引。重复抽样不是新增独立帧。各帧输入NPZ保存原ADC、I/Q符号、FFT功率；恢复谱NPZ及最终输出是相对幅值；PNG不用于训练。

## 选模与质量

每组CPU训练8000步，在2000/4000/6000/8000步用验证集选择：先少主要目标半幅失败，再少参考外峰，再少最强伪峰、超额能量、目标误差。弱目标丢失不一票否决。

主候选最终判据：40m内主要目标均≥参考半幅；残峰比独立恢复减少≥20%、比恢复接旧网减少≥10%；超额能量比独立恢复减少≥20%；跨帧最强伪峰不高于独立恢复。均为本轮预声明研究判据。弱目标的损失、放大和距离分组另报，不用平均背景改善掩盖。

## 复现

工作区根目录执行`run.py prepare`、`run.py train`、`run.py test`。依赖本工作区v2与scalar_multipeak48_v1，源文件/旧权重SHA在FROZEN.json及各数据清单。冻结后禁止覆盖训练；后续实验另建目录。

后级推理入口`infer.py --input 输入.npz --output 输出.npz`，输入只需`recovered_amplitude`（1024×512归一化幅值）和`original_onebit_peak`（原单比特功率峰标量）。它不接受真值/多比特参考，不包含前面的残差恢复求解。

必须使用本目录`infer.py`或`run.net_gain()`应用本轮1/64增益下限。依赖目录旧`Model.gain()`和旧整数LUT仍为1/8下限，直接用旧接口会改变结果；本轮没有适配旧PL整数实现。原始权重文件不能单独拷入旧硬件代替完整数值适配。

最终结果已完成：主候选通过本轮小规模去伪优先判据，主要目标32/32保持半幅以上，但弱目标12/14不足半幅。仍存在强互调伪峰，不称完全恢复。补充见[剩余错误与阈值对照](剩余错误与阈值对照.md)。

本轮仅PC浮点试验。前端仍包含CPU迭代，整体不是轻量实时PL实现。若效果可取，后续才考虑数值适配、简化前端或蒸馏，不能直接上板。
