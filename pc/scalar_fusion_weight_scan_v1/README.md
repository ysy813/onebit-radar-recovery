# 全局融合比例扫描

先看[本轮结果](本轮结果.md)，图像为[中文图集](results/index.html)，数据来源见[数据索引](数据索引.md)。

本轮只改变输出融合比例：旧40维网络、残差求解器、回波两电平规则和保护条件全部冻结。没有重新训练MLP，也没有IP/BIT或板卡操作。它仍是PC浮点符号恢复原型，不能因为融合公式简单就认为整条支路可轻量部署。

## 方法与端点

主接口先计算`(1−α)×旧网幅值＋α×恢复幅值`，再在v2支持掩膜内取它与旧网/旁路幅值的最大值。保持保护规则是为了只考察权重变化。α=0表示仅保护接口；α=1表示带保护恢复。二者分别不完全等于纯旧网和独立恢复。

另用相同101点网格计算不带保护的纯融合，以区分权重与保护层的影响；不按测试结果把辅助接口替换成主候选。纯旧网和独立恢复单列。两种融合都在相对幅值域进行，不是功率域或复频谱融合。

## 数据与选择顺序

- 6帧复用v2验证数据：扫描α=0～1，步长0.01，选择比例。这些场景已经看过，不称盲测；101种比例不是101倍独立数据。
- 12帧v2旧测试：作为已看过的诊断数据，只运行冻结比例及对照，不参与选择。
- 冻结后生成12帧新测试：种子20261112000～20261112011，最后检验。无噪声、无杂波、无窗的单/多点频回波，先叠加再量化；包括强弱、相邻及谐波重合。
- 本轮没有训练数据集或新增权重更新；恢复求解在每帧估计参数不等于训练MLP。旧权重仍继承历史训练数据影响。

先筛选“新增半幅失败=0、任一目标保留率下降≤0.05、目标MAE增加≤0.005”的权重，再依次比较参考外峰均值、最差纯谐波相对旧网增幅、目标MAE与更小α。未要求选参阶段所有目标都达到半幅，因为旧网本来可能失败；最终质量另要求全部半幅通过、参考外峰减少≥10%、任一纯谐波区域相对旧网恶化≤1dB。阈值为预声明研究判据，不是行业标准。

目标指标取真目标5×5邻域的多比特参考最大频点，各方法读取相同位置。参考外峰口径沿用v2：排除真目标9×9区域，输出≥0.01、超过参考2倍且超额幅值>0.0001的3×3局部峰，再5×5抑制。谐波区域也沿用v2纯区域条件。所有真值仅用于选参评价，不作为融合输入。

最终结果中的半幅边缘样本敏感性单列，未事后修改门槛，也未根据新测试重新选参。并不把“网格无可用非零比例”夸大成任意连续正比例数学上都不可用。

## 复现入口

工作区根目录使用本机Python依次执行本目录`experiment.py scan`、`experiment.py diagnostic`、`experiment.py test`，然后`deliver.py report`、`deliver.py check`。已冻结后禁止重新scan覆盖；新测试按冻结SHA校验并复用已完成帧。后续新实验应使用新目录。

运行依赖v2及scalar_multipeak48_v1的源码与模型，完整绝对路径和SHA记录在FROZEN.json；本目录不是可脱离工作区的独立模型包。输入NPZ存回波/符号/FFT功率，结果NPZ存相对幅值，PNG仅供展示。

标准检查与质量分开：reports/STANDARD_CHECK.json检查实现与来源，reports/TEST_SUMMARY.json记录新场景质量。未通过时不能替换已部署模型。
